Assembly Tokenizer & Symbol Table Generator

The first pass of an assembler, written entirely in MIPS assembly. A finite state machine reads each line character by character, splits it into typed tokens, then a symbol table records every label definition and reference along with its address.

Built in three stages: character classification, then the state machine tokenizer, then the symbol table. After submission I tracked down a register-saving bug that made symbols appear multiple times and fixed it.

How to Use & Test

Step-by-step guides so you can run my projects on your own machine. Each guide lists what you need first.

SecureDrop

Source code: github.com/AZALAH/SecureDrop

  1. Install Python 3.10 or newer.
  2. Clone the repo: git clone https://github.com/AZALAH/SecureDrop.git, then cd SecureDrop.
  3. Install the one dependency: pip install -r requirements.txt.
  4. Run python src/secure_drop.py and register with a name, email, and password.
  5. Run it again to log in, then type help at the secure_drop> prompt.
  6. Add a contact with add, see who's online with list, and send an encrypted file with send friend@email.com ./file.txt.
  7. No second computer? Set LOCAL_TEST = True in the code and use src/test_friend.py to simulate another user.

Assembly Tokenizer

Source code: github.com/AZALAH/Assembly-Tokenizer

  1. Install Java, then download the MARS 4.5 MIPS simulator (Mars4_5.jar).
  2. Download src/symbol_table.asm from the repo.
  3. Open it in MARS, press F3 to assemble, then F5 to run.
  4. In the Run I/O panel, type a line of assembly ending in #, like FIRST: li $t0, VALUE #.
  5. You'll see every token with its type, then the symbol table with each label and reference and its address.
  6. Keep entering lines and watch the addresses climb by 4. Compare with examples/expected_output.txt.
